A program that writes a single-line joke about office life (106 characters): "The meeting ended with one action item: schedule a meeting about why the last meeting had no action items." The sort of line you send a colleague right after a meeting that should have been an email — the meeting's only outcome is another meeting, about the previous meeting's failure.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes the joke to `out/entry.txt` and verifies it byte-for-byte (SHA-256) against `line.txt`.
